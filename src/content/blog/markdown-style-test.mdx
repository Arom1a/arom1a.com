## Paragraphs

This is a paragraph with **bold text** and *italic text* and ***bold italic***.

This is another paragraph with `inline code` and more text.

## Links

[Link to Google](https://google.com)

## Lists

### Unordered List

- Item 1
- Item 2
  - Nested item 2.1
  - Nested item 2.2
- Item 3

### Ordered List

1. First item
2. Second item
   1. Nested item 2.1
   2. Nested item 2.2
3. Third item

## Blockquote

> This is a blockquote.
> It can span multiple lines.
>
> And have multiple paragraphs.

}
